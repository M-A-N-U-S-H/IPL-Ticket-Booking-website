# IPL Ticket Booking Website

A responsive, dynamic web application built to simulate an IPL ticket booking platform. This project showcases structured semantic HTML5 layouts, modern CSS variables styling, and active JavaScript state calculations.

## 🚀 Features Implemented

- **Activity 1: Structure (HTML5)**
  - Semantic tags layout (`nav`, `section`, `footer`).
  - Match schedule table showing fixture data.
  - Interactive booking forms alongside real-time summary panels.
  - Informational guideline item containers.

- **Activity 2: Interface Styling (CSS3)**
  - Clean layout utilizing custom root CSS global color tokens.
  - Responsive flexbox alignment parameters.
  - Modern dark-blue and polished gold design theme patterns.

- **Activity 3: Business Logic (JavaScript)**
  - Live filter controls targeting target matching criteria.
  - Dynamic price summaries responding to selected tiers.
  - Local state execution updates recording mock verification slips.
